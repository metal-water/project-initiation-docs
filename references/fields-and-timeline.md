# 字段、周期与删除规则

## 字段状态

同一项目两稿共用字段状态、值与来源。新指令更新当前项目，不把历史年份、主体或金额变成全局默认。

| 字段 | 处理规则 |
| --- | --- |
| 预算金额 | 默认 `blank_yellow`：保留标题、科目、单位与填写位置，删除实际金额及派生描述，黄色空白由财务填。明确要求且有依据可用 `fill_yellow`。只说“标黄”则保留现值 |
| 研发人员人数 | 默认 `blank_yellow`，不据参考人数推算编制或成本。姓名、负责人、人数是不同字段，不自行扩大范围 |
| 立项周期 | `source` 按指定材料；`planned` 在授权区间内拟定阶段；`blank_yellow` 清空待核；`highlight_existing` 保留现值标黄。确认且要求不用标黄时去掉时间黄色 |
| 阶段计划 | 与周期模式一致；时间留空时同步处理各阶段日期及“共N个月”等时长，不能只空封面 |
| 签署日期 | 与研发区间分开，年度计划授权不代表审批日期获确认，不能填今天或阶段开始日 |
| 游戏人数 | 玩家数、队伍数、战斗人数、关卡数等不是研发人数，按内容保留 |
| 名称和主体 | 核查封面、正文、表格、图注、目录、页眉页脚；历史合作方、版权人和公司背景不能机械换名 |

“标黄”和“标黄留空”不同。前者保留内容，后者清除值并留下可填写位置；不要用0、虚构值或整段“预算待定”代替空白。

## 可见的黄色空白

表格待填格留足尺寸并加黄色底纹；行内使用保留空格的黄色高亮run或符合原稿样式的填写线。空run没有字符时高亮可能不可见，必须渲染确认。数值清空后保留“总预算”“万元”等说明，不能破坏句子和布局。

检查正文、表格、图表、图片、图注、批注、修订删除文本、替代文字和嵌入对象中的同类数据。只删正文而在图片或附件中留数值不算完成。

## 时间安排

**按材料沿用**：提取用户指定文档的准确起止区间，有矛盾列出核对；不套其他项目的一年计划。来源只有总体周期而旧稿另有冲突的阶段日期时，不能原样带入新稿，也不能虚构为来源记载；具体阶段时间可保留待确认，先完成总体周期及其他有依据的修改。用户授权拟定阶段后才按计划口径编排，不宣称这些阶段来自原文。

**用户授权编排**：“2025年1到12月内，你看着拆，注意合理性”已经授权拟定计划，不反复询问每个阶段。按项目成熟度与实际任务安排，不宣称存在唯一行业标准周期。可按需求和核心玩法验证、核心系统开发、内容制作与整合、联调与性能测试、优化交付和验收组织，阶段数及月份随项目调整。允许有理由的并行，所有日期落在区间内，依赖关系合理，两稿一致。计划不证明某历史月份确已测试、验收或获批。

**待核与更新**：按“保留标黄”或“清空标黄”处理。用户后来授权周期并取消时间高亮，就同步填回阶段与全文时间，仅取消时间黄色，保留预算与人力高亮。

## 多年预算不能直接压缩到一年

旧总额、单年投入与新一年总预算不是同一口径。缺少主体、范围、期间、科目和调整依据时，不能平均摊分、按时间比例推算或择一回填。用户要求“能对上填并标黄，否则留空”时先检查这些依据；不足则留空。用户已说“忽略预算，财务填”时不再要求其从旧金额中选择。

## 先排除PPT预算人数页，再同步清下游

1. 以最少必要信息定位页面，如标题、页号或本地结构。不要先把被排除页的全文、截图和备注送入起草输入。
2. 保留原PPT，制作删页副本或明确排除页的取材集合。PPT预算／人数页按用户要求整页排除；其他类型混合页可提取不含被排除数据的研发内容。
3. 检查副本里的备注、图表、嵌入表格及孤立部件不会被后续通用提取器读出。取材依据是干净副本的有效内容，不遍历原始包中的排除部件。
4. 已经读过时如实说明从后续起草输入中排除，不能声称消除了既有上下文。重查两稿直接金额、团队规模、派生总额、人月、人力成本、相关说明、图表、图注与附件。
5. “PPT移除了，文档也不该显示”要求对应下游同步删除，只删源页或只清预算表均不足。保留模板所需黄色空白栏，不留旧数据解释段。
